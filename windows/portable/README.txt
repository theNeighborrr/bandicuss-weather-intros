BANDICUSS WEATHER — WINDOWS ONE-CLICK EDITION

1. Right-click the downloaded ZIP and choose Extract All.
2. Open the extracted Bandicuss Weather folder.
3. Double-click START BANDICUSS.cmd.

No Python installation, commands or administrator access are needed.
For Windows 10/11 on Intel or AMD 64-bit PCs. Native ARM64 and 32-bit
packages are not included. Internet is needed for first launch and weather.

The first launch automatically downloads and verifies the reviewed Bandicuss
Weather v4.1 application from its author's GitHub repository. Python and the
display libraries are already included. Later launches use the saved copy.
Windows Terminal is used when available; Windows Console is the fallback.

Press Enter for Memphis (KMEM), or type another four-letter ICAO station.
I: Intro settings. 1: ASCII. 2: Pixel. 3: Off. P: Preview. B: Back.
Any key skips the intro. Q exits the weather menu. Ctrl+C also exits.
Off disables startup only; Horizon still shows live weather acquisition.
Maps and other graphical products open in your usual browser.

KEEP THE WHOLE FOLDER TOGETHER. You can move the extracted folder when the
app is closed. Its app and preferences travel with it under data/installation.
To create a desktop shortcut, right-click START BANDICUSS.cmd and use
Send to > Desktop (create shortcut); keep the folder in its chosen location.

No automatic updates, login startup or background services are installed.
Your existing Bandicuss installation and its preferences remain separate.
To remove this edition, close it and delete its folder and any shortcut.
To update, extract a newer ZIP into a separate folder; preserve the old data.
If a file check reports changes, keep your files and extract a fresh copy.
If first launch cannot connect, retry when online. Failed setup is preserved.
